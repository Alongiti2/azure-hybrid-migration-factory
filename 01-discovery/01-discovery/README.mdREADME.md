# 01 - Customer Discovery

This folder contains the customer discovery and environment inventory artifacts for the Azure Hybrid Migration Factory.

## Scope

Discovery covers:

- Compute
- Virtual machines
- Applications
- Databases
- Storage
- Networking
- DNS
- Identity
- Security
- Monitoring
- Backup
- Disaster Recovery
- Compliance
- Licensing
- Dependencies
- Business requirements
- RTO/RPO
- Migration constraints

## Primary Customer Scenario

Contoso Manufacturing

## Source Platforms

- Azure Stack Hub
- Azure Stack Edge

## Goal

Create a complete, evidence-based inventory before making migration decisions.
